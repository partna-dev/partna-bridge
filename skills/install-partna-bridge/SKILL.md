# Установка partna-bridge

Полные шаги — в `INSTALL.md` в корне репозитория. Здесь только порядок и границы.

1. Спросить у владельца: ключ тенанта, адрес сайта для возврата, публичный адрес моста, название программы.
2. Запустить `./scripts/install.sh`.
3. Прогнать проверки: `/health`, `/r/<код>` с cookie, `401` на заказ без токена, `401` на вебхук без подписи.
4. Зарегистрировать вебхук: `partner-network webhook-set --tenant … --url … --secret …`.
5. Отчитаться одной строкой.

Не печатать секреты. Не менять DNS и сертификаты без подтверждения человека.
