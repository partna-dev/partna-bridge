# Поля и ошибки

Справка по телам запросов. Машиночитаемый вариант — `/openapi.json` работающего моста: там те же
поля с типами и обязательностью.

## Общее правило

`eventId` — устойчивый идентификатор события у владельца. Очередь моста отбрасывает повтор по этому
полю, ядро дедуплицирует по нему же. Случайный UUID на каждый вызов превращает один платёж в два.

`occurredAt` — когда событие произошло у владельца, ISO 8601 с часовым поясом:
`2026-11-19T12:00:00Z` или `2026-11-19T18:00:00+06:00`.

`amount`, `retailAmount`, `certificateAmount` — **минорные единицы**. `350000` при `RUB` — это
3 500 ₽, при `KZT` — 3 500 ₸.

## POST /v1/order

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `eventId` | string | да | идентификатор платежа у владельца |
| `occurredAt` | datetime | да | момент оплаты |
| `orderId` | string | да | номер заказа у владельца |
| `memberId` | string | да | покупатель, тот же id, что в `claim` |
| `amount` | integer | да | сумма платежа, минорные единицы |
| `currency` | string | да | три буквы, заглавными: `RUB`, `KZT` |
| `personalVolume` | number | да | объём для расчёта; если не используется — `0` |
| `productId` | string | нет | ключ товара из каталога владельца |
| `eventAt` | datetime | нет | дата события для расчёта, если отличается от оплаты |
| `retailAmount` | integer | нет | розничная сумма |
| `certificateAmount` | integer | нет | сколько покрыто сертификатом |

## POST /v1/refund

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `eventId` | string | да | идентификатор возврата |
| `occurredAt` | datetime | да | момент возврата |
| `refundId` | string | да | номер возврата у владельца |
| `orderId` | string | да | какой заказ вернули |
| `memberId` | string | нет | покупатель; ядро возьмёт его из заказа |
| `amount` | integer | да | сумма возврата, минорные единицы |
| `currency` | string | да | валюта возврата |

## POST /v1/member

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `eventId` | string | да | `member:<id>:<спонсор или root>` |
| `occurredAt` | datetime | да | момент появления участника |
| `memberId` | string | да | идентификатор человека |
| `sponsorId` | string | нет | кто пригласил |
| `placementId` | string | нет | место в дереве |
| `leg` | `left` \| `right` | нет | сторона в бинарной структуре |
| `status` | `active` \| `inactive` | нет | по умолчанию `active` |

## POST /v1/claim

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `code` | string | нет | код партнёра; если пусто — берётся из cookie `pn_ref` |
| `externalAccountId` | string | да | идентификатор клиента у владельца |

С `Authorization: Bearer <BRIDGE_BRIDGE_TOKEN>` лимит на адрес не действует: так делает серверный
вызов уровня 2. Без токена — 30 запросов в минуту с адреса.

## POST /v1/partner-link

| Поле | Тип | Обязательно | Смысл |
|---|---|---|---|
| `externalAccountId` | string | да | чья ссылка |
| `destinationUrl` | string | нет | куда вести; по умолчанию `BRIDGE_DESTINATION_URL` |

Ответ `url` указывает на домен ядра. Ссылку для партнёра собирайте на домене моста:
`https://<мост>/r/<code>`.

## Коды ответов

| Код | Что значит |
|---|---|
| `200` | ядро приняло факт сразу (режим `inline`) |
| `202` | факт в очереди (режим `queue`), это норма |
| `400` | нет кода партнёра, самоприглашение, окно привязки истекло |
| `401` | нет или неверен `Bearer`-токен |
| `409` | конфликт связей: у клиента другой спонсор, спонсор заблокирован |
| `422` | не хватает поля или поле неверного типа, неизвестный спонсор |
| `429` | сработал лимит `claim` для браузерных вызовов |
| `502` | ядро недоступно; в режиме `queue` такого ответа не будет |
| `503` | в мосте не задан `BRIDGE_BRIDGE_TOKEN` |

## Ошибки, которые стоят денег

1. **Сумма в рублях вместо копеек.** Комиссия считается от `amount`; ошибка на два порядка.
2. **Новый `eventId` на каждый повтор.** Двойное начисление по одному платежу.
3. **`memberId` партнёра вместо покупателя.** Комиссия уйдёт не туда или не начислится вовсе.
4. **Заказ на `pending` и `canceled`.** Начисление появится по оплате, которой не было.
5. **`refund` не отправлен.** Клиент получил деньги назад, партнёр остался с комиссией.
6. **Ссылка на домене ядра.** Cookie моста не ставится, привязка теряется.
